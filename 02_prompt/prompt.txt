## Prompts in LangChain: Key Notes

    *   The message sent to an LLM is called a prompt.

*   **Static vs. Dynamic Prompts (10:30 - 27:05)**

    *   **Static Prompt:** Hardcoded prompt; lacks user input control and flexibility.
    *   **Dynamic Prompt:** Uses placeholders filled at runtime; offers more consistency and control.
    *   **PromptTemplate Class:** Used for creating dynamic prompts with specific inputs.
        *   Benefits: Validation, reusability, and tight integration with LangChain's ecosystem (e.g., Chains).

*   **Messages in LangChain (36:49 - 56:31)**

    *   **System Message:** Sets the initial role or behavior of the assistant.
    *   **Human Message:** Messages sent by the user.
    *   **AI Message:** Responses generated by the LLM.
    *   Importance: Labeling messages ensures the LLM maintains context during long conversations.

*   **Chat Prompt Templates (56:31 - 01:06:37)**

    *   Used specifically for multi-turn conversations involving lists of messages.
    *   Allows for dynamic system and human messages within the conversation history.

*   **Message Placeholder (01:06:37 - 01:17:29)**

    *   A specialized placeholder used within `ChatPromptTemplate`.
    *   Function: Allows for the dynamic insertion of chat history (a list of messages) at runtime to provide context for new queries.
